# Skills

Agent skills I use and share. Each folder is one skill: a `SKILL.md` plus the reference files and assets it reads.

## Strategy Builder

[`strategy-builder/`](strategy-builder/) runs a full strategy session for a product, company or idea, built on Alex M H Smith's book *No Bullsh\*t Strategy*.

- **The interview.** It interviews the founder one question at a time and researches the market.
- **Who writes the ideas.** Three independent strategists write the strategy ideas.
- **How they're judged.** Blind judges score each idea against the book's real examples, such as Starbucks, Southwest and IKEA. Only ideas scoring 8 out of 10 go forward.
- **What you get.** One shareable HTML report:
  - a strategy to hold if the product stays where it is;
  - one or two strategies that move it into open ground nearby;
  - more directions to explore.

It works best on the most capable model you have, with reasoning set high.

**Install (Claude Code):** copy the `strategy-builder` folder into `~/.claude/skills/` (for you) or `.claude/skills/` in a project (for everyone on that project). Then ask "let's work on the strategy for X".

**Credits:** the method comes from *No Bullsh\*t Strategy* by Alex M H Smith. Read the book; the toolkit here is only notes on it with page references. The messaging rules draw on Brand Boss ([@brandbosshq](https://www.tiktok.com/@brandbosshq)).
